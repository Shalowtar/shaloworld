写一个猴子吃桃的程序，求摘了多少桃吃。

## 题目

猴子吃桃问题：猴子第一天摘下若干个桃子，当即吃了一半，还不过瘾，又多吃了一个。第二天早上又将剩下的桃子吃掉一半，又多吃了一个。以后每天早上都吃了前一天剩下的一半零一个。

到第 10 天早上想再吃时，见只剩下一个桃子了。求第一天共摘了多少？

## 代码

```c
#include <stdio.h>
void calc(int *n)
{
	*n += 1;
	*n *= 2;
}
int main() 
{
	int n = 1;
	int i = 1;
	do
	{
		calc(&n);
		i++;
	} while (i != 10);
	printf("猴子总共摘了%d个桃\n", n);
	return 0;
}
```

## 复盘

第一次写的时候没写成指针，导致传入计算根本没有效果。

修改成传指针，直接修改 `n`，然后就完成了。
